# Shaurya Chaudhary — Personal Portfolio

A personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my education, skills, projects, achievements, and contact information.

## About

This portfolio is designed as a personal professional website for **Shaurya Chaudhary**, a Computer Science student interested in software engineering, artificial intelligence, and digital product development.

## Website Sections

- **Home** — Introduction, personal branding, and main navigation.
- **Skills** — Technical skills and learning progress.
- **Education** — Academic background and milestones.
- **Projects** — Selected software and development projects.
- **Achievements** — Certificates and achievements, with room for future additions.
- **Contact** — Contact information and enquiry/contact form.

## Technologies

- Responsive web design

## Running Locally

No framework, package manager, or build process is required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

For development, VS Code with Live Server can be used.

## Deployment

This website can be hosted as a static website using **GitHub Pages** because it is built with HTML, CSS, and JavaScript.

Recommended GitHub Pages settings:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```
